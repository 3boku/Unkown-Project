# BK-02 기획서 웹 폼 (입력·수정·자동 저장) 구현 계획

> **For Claude / Antigravity:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 오거나이저가 행사 정보(`EventPlan`)를 입력·수정하고 `localStorage`에 자동 저장하며, 필수 필드 유효성 검사 및 실시간 프리뷰 연동을 지원하는 기획서 웹 폼을 구현한다.

**Architecture:** Next.js Client Component(`PlanForm.tsx`)에서 Zod 기반 `EventPlan`을 제어 컴포넌트로 관리한다. 입력 변경 시 브라우저 `localStorage`(`lib/storage.ts`)에 즉각 동기화되며, "샘플 불러오기" 버튼으로 `fixtures/sample-plan.json`을 채울 수 있다. 상위 `page.tsx`에서 상태를 공유하여 사실 필드(일시, 장소, 연사, 스케줄 등) 수정 시 우측 프리뷰에 실시간 반영된다.

**Tech Stack:** Next.js 16.4.2 (App Router, Client Components), React 19, TypeScript 5, Zod 4, Tailwind CSS 4, `lib/tokens.ts` (색상 토큰 엄수).

### Task 2: `PlanForm.tsx` 컴포넌트 구현

**Files:**
- Create: `components/PlanForm.tsx`

**Features to implement:**
1. **헤더 & 액션바**:
   - "샘플 기획서 불러오기" 버튼 (Build with AI 2026 샘플 즉시 입력)
   - "새 기획서 작성 (초기화)" 버튼
   - 자동 저장 상태 표시기 ("저장됨" / "수정 중...")
2. **기본 행사 정보 섹션**:
   - 테마 선택: `BUILD_WITH_AI`, `IO_EXTENDED`, `DEVFEST`
   - 연도 (`year`), 행사명 (`title`), 주최 (`hostName`)
   - 후킹 문구 (`hook`), 상세 소개 (`description`)
   - 일시: 행사 날짜 (`date`, type="date"), 시작 시간 (`startTime`, type="time"), 종료 시간 (`endTime`, type="time")
   - 장소 (`venue`), 정원 (`capacity`, number)
   - 프로그램 요약 (`programSummary`), 대상 청중 (`targetAudience`)
   - 참가 혜택 (`perks`, 태그 추가/삭제)
3. **신청 정보 섹션 (`registration`)**:
   - 플랫폼 (`EVENTUS`, `TICKETTACO`, `OTHER`)
   - 신청 링크 URL (`url`)
   - 신청 마감일 (`deadline`, type="date")
4. **타임테이블 섹션 (`schedule`)**:
   - 행 추가/삭제/수정: 시작 시간(`start`), 종료 시간(`end`), 세션명(`title`), 비고(`note`), 하이라이트 여부(`highlight` 체크박스)
5. **연사 목록 섹션 (`speakers`)**:
   - 연사 카드 추가/삭제/수정
   - 이름(`name`), 소속/직책(`affiliation`), 발표 세션명(`sessionTitle`), 소개 요약(`summary`)
   - 구분: `HANDS_ON` / `SESSION`
   - 사진 입력: 이미지 파일 선택(FileReader `readAsDataURL` 변환) 또는 이미지 URL 직접 입력
6. **특별 이벤트 & 후원사 섹션 (`specialEvents`, `sponsors`)**:
   - 특별 이벤트: 제목(`title`), 설명(`desc`) 추가/삭제/수정
   - 후원사: 태그 추가/삭제
7. **생성 버튼 및 유효성 피드백**:
   - 필수 필드 6종(`theme`, `year`, `title`, `date`, `startTime`, `venue`) 미입력 시 "생성" 버튼 비활성화 및 누락 필드 안내 배지 노출
   - 필수 필드 충족 시 "✨ 브랜드 킷 생성" 버튼 활성화

**규칙 체크:**
- `#[0-9A-Fa-f]{6}` 색상 코드를 직접 쓰지 않고 `lib/tokens.ts`의 `color.*` 상수 및 Tailwind CSS 활용.
