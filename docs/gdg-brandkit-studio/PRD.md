> 문서 상태: v1.0 (2026-10-18) · 개발 제한 시간: **90분** · 개발 도구: Google Antigravity

## 1. Summary

GDG 오거나이저가 웹 폼에 행사 기획서를 입력하고 테마를 고르면, 티켓팅 썸네일·인스타 카드뉴스·릴스 영상 프리뷰·SNS 문구를 한 번에 만들어 주는 웹 도구입니다. 기획서는 언제든 수정할 수 있고, 각 에셋은 추가 프롬프트로 개별 수정할 수 있습니다.
이 문서는 **90분 안에 시연 가능한 MVP**의 범위와 성공 기준을 정의하고, 그 이후 확장 범위를 구분합니다.

## 3. Background

- **문제:** 지역·캠퍼스 GDG 행사 하나에 썸네일 2종, 카드뉴스 6~10장, 릴스 1편, SNS 문구가 필요합니다. 대부분 자원봉사 오거나이저가 Figma·캔바로 매번 손으로 만들며, 행사 하나에 반나절 이상이 걸립니다.
- **기존 방식의 한계:** 이미지 생성 AI에게 포스터를 통째로 그리게 하면 한글이 깨지고, 로고 비율과 Google 브랜드 컬러가 틀어집니다.
- **지금 가능한 이유:** Gemini의 Structured Outputs로 기획서에서 일관된 홍보 문구 JSON을 한 번에 만들 수 있고, Satori(JSX → 이미지)와 Remotion(React → 영상)으로 글자를 코드로 정확하게 배치할 수 있습니다. Antigravity 같은 에이전트 IDE 덕분에 템플릿 코드를 짧은 시간 안에 작성할 수 있습니다.

## 4. Objective

**목표:** 오거나이저가 기획서 한 장으로 행사 홍보 에셋 전체를 10분 안에 준비하게 만듭니다. 디자인 품질은 Google 브랜드 가이드를 지키는 수준이어야 합니다.

### OKR (해커톤 90분 + 이후 1분기)

**정렬 대상:** GDG 커뮤니티 목표 "오거나이저의 운영 부담을 줄이고 행사 홍보 품질을 높인다"

#### Objective 1 — 기획서 한 장이 브랜드 킷 전체가 되는 경험을 증명한다 (90분 데모)

| # | Key Result | Baseline | Target | Owner |
| --- | --- | --- | --- | --- |
| KR1 | 기획서 입력 완료 후 "생성" 클릭부터 4개 탭이 채워질 때까지 걸리는 시간 | 수동 제작 반나절 | **≤ 30초** | 개발 |
| KR2 | 기획서 하나로 생성되는 산출물 종류 | 0 | **4종** (썸네일, 카드뉴스, 릴스 프리뷰, SNS 문구) | 개발 |
| KR2-b | 프롬프트 수정 1회로 원하는 결과를 얻은 비율 (데모 시나리오 5개 기준) | — | **≥ 4/5** | 개발 |
| KR3 | 산출물에 쓰인 색이 브랜드 토큰 7개 밖으로 벗어난 사례 | — | **0건** (grep 검사) | 디자인 검수 |
| KR4 | Cloud Run 공개 URL에서 끝까지 시연 성공 | — | **연속 3회 성공** | 개발 |

#### Objective 2 — 오거나이저가 결과물을 고치지 않고 바로 쓸 만큼 품질을 높인다 (1분기)

| # | Key Result | Baseline | Target | Owner |
| --- | --- | --- | --- | --- |
| KR1 | 생성된 카드뉴스를 수정 없이 게시한 비율 | — | **≥ 60%** | PM |
| KR2 | 한글 깨짐·텍스트 넘침 신고 건수 | — | **행사당 ≤ 1건** | 개발 |

> 카운터 지표: KR1은 "게시율"만 보면 품질이 낮아도 급해서 올리는 경우가 섞입니다. 게시 후 오거나이저가 남긴 수정 요청 수를 함께 봅니다.

#### Objective 3 — 홍보 마지막 단계(게시)까지 자동화한다 (1분기)

| # | Key Result | Baseline | Target | Owner |
| --- | --- | --- | --- | --- |

**점검 주기:** 해커톤 중에는 30분마다 Objective 1 진행 상황을 확인하고, 이후에는 주 1회 신호등(초록·노랑·빨강)으로 점검합니다.

## 5. Market Segment

- **핵심 사용자:** 행사를 준비하는 GDG 챕터·GDG on Campus 오거나이저. 디자이너가 없고, 시간이 부족하며, Google 브랜드 가이드를 지켜야 합니다.
- **해결하려는 일(Job):** "행사 공지가 확정되면, 오늘 안에 티켓 페이지와 인스타 홍보를 시작하고 싶다."
- **제약:** 예산이 거의 없습니다(무료 크레딧 수준). 사용 빈도가 낮습니다(행사당 1~3회). 한국어 텍스트가 많습니다.

## 6. Value Proposition

| 고객이 겪는 문제 | 이 제품이 주는 가치 |
| --- | --- |
| 에셋마다 같은 정보(일시·장소·연사)를 반복 입력합니다 | **웹 기획서에 한 번 입력**한 내용이 모든 산출물에 들어가고, 고치면 모두 함께 바뀝니다 |
| AI 결과물을 조금만 고치고 싶어도 처음부터 다시 만들어야 합니다 | **에셋별 추가 프롬프트**로 그 에셋만 고치고, 마음에 안 들면 되돌립니다 |
| AI 이미지 도구는 한글·로고를 망가뜨립니다 | 글자와 로고는 **코드 템플릿**이 배치하므로 깨지지 않습니다 |
| Google 컬러를 매번 눈으로 맞춥니다 | **디자인 토큰 4색 + 무채색 3색**이 코드에 고정되어 있습니다 |
| 릴스 편집은 전문 도구와 시간이 필요합니다 | 스토리보드 JSON만 고치면 **브라우저에서 바로 재생**됩니다 |

**경쟁 대비:** 캔바 템플릿은 정보를 칸마다 직접 채워야 하고, 범용 AI 이미지 도구는 글자 품질이 낮습니다. 이 제품은 "기획서 → 구조화 데이터 → 코드 렌더링" 흐름으로 두 문제를 동시에 해결합니다.

## 7. Solution

### 7.1 UX 흐름 (90분 MVP 기준)

```
[1. 기획서 입력] 화면 왼쪽 웹 폼: 테마, 제목, 일시·장소, 소개, 타임테이블, 연사, 이벤트
      (입력할 때마다 브라우저에 자동 저장 → 언제든 다시 열어 수정)
      ↓  "✨ 브랜드 킷 생성" 클릭
[2. 생성]  Gemini가 카드 문구·릴스 대본·SNS 캡션 생성
      ↓
[3. 프리뷰] 화면 오른쪽 탭 4개
      ├─ Tab 1 썸네일: 이벤터스 1280x720, 티켓타코 1200x630 PNG
      ├─ Tab 2 카드뉴스: 1080x1350, GDG Campus Korea 인스타 포맷, 좌우로 넘겨보기
      ├─ Tab 3 릴스: Remotion Player 9:16 실시간 재생
      └─ Tab 4 SNS 문구: 인스타 캡션, 스레드 본문 + 대댓글 (복사 버튼)
      ↓
[4. 다듬기] 에셋마다 프롬프트 입력창: "제목을 더 짧게", "빨간색 위주로" → 그 에셋만 수정, 되돌리기 가능
            사실(날짜·연사 등) 변경은 왼쪽 폼에서 → 모든 에셋에 즉시 반영
      ↓
[5. 다운로드] PNG 개별 다운로드 (ZIP은 여유 시간 과제)
```

### 7.3 Technology

세부 사항은 [SPEC.md](./SPEC.md)를 따릅니다. 요약하면 Next.js 단일 앱 + Gemini(Structured Outputs) + `next/og`(Satori) + Remotion Player이며, Cloud Run 서비스 하나에 배포합니다. 데이터는 브라우저 localStorage에만 저장합니다.
